Strategic Focus Areas & Transformation Opportunities
•Standardize on fewer MS SQL Patterns.
•On-Prem is targeted for public cloud modernization.
•Target MS SQL pattern for Azure is Managed Instance
•Target MS SQL pattern in AWS is RDS
•MS SQL is predominantly for smaller databases with smaller transactional demands.
•
•Workload targets:
•Small to Medium sized databases with respective transactional demands are well suited to MS SQL.
•Medium to High sized databases with respective transactional demands are well suited to Oracle Exadata.
•
•DB2 is deprecated and has been in containment mode for a decade. Footprint has since been shrinking but strategic modernization needs to speed the process up. Oracle Exadata is the best candidate for technology replacement of DB2.
•
•All legacy Oracle DBMS has been migrated to Exadata. In Q3 2026 it is planned to move all corresponding workloads from Cloud at Customer to Exa@Azure. For the duration of this road map, it is expected that all landing of Oracle workloads will occur onto our Exa@Azure environment.
•
•AI Readiness is well suited to Oracle 26ai database technology. Databases already hosted on Oracle 19c can get upgraded directly into 26ai and start taking advantage of AI features and storage mechanisms. MongoDB can be natively stored directly in Oracle 26ai containers.
•The adaption of Oracle Autonomous Database technology offers self healing, auto patching, and a reduction of operational support needs. We should focus on this over the course of this roadmap.
